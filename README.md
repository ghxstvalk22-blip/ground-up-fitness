# Ground Up Fitness

Simple training plans and free tools for losing weight, getting stronger, or starting at the gym for the first time.

Built by Christopher Dippold for ISCI 250.

- **Want something added?** Write it under **Up next** in [`ROADMAP.md`](ROADMAP.md). The daily update builds the top item.
- **What changed recently?** See [`CHANGELOG.md`](CHANGELOG.md).
- **Undo a change:** open the commit on GitHub and use **Revert**, or ask Claude to roll it back.

Information on this site is general fitness education, not medical advice.
