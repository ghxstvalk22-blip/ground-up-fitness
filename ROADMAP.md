# Roadmap

Add an idea anywhere under **Up next** and the daily update will build it, top item first.
Write it in plain words, like `- [ ] Add a page about stretching before workouts`.

## Up next

Owner priorities (2026-10-12): more workout plans, and more dropdowns and links that move visitors around the site.

- [ ] Programs dropdown: list every plan by name and days (for example "Lose fat · 4 days") so each one is one click from the menu. Add a menu entry automatically whenever a new plan is added.
- [ ] New program "Build muscle" (hypertrophy) for 3 days a week: a gentler full-body muscle plan for people who aren't ready for the 4- and 5-day Classic Physique split. Add its radio button, quick-start tile, and menu link (hero counts update on their own).
- [ ] "Next step" links: at the end of each section (Start here, Program builder, Tools, Gym basics) add a short "Where to next?" row of buttons that sends visitors to the most useful related section, so nobody hits a dead end.
- [ ] New program "No gym / bodyweight" for 3 days a week: push-ups, squats, lunges, glute bridges, rows with a table or backpack, planks, each with an easier and a harder version.
- [ ] Gym basics in the menu: make Gym basics its own top-level dropdown that lists every FAQ question and opens that answer when clicked.
- [ ] New program "Busy schedule" for 2 days a week: two full-body sessions that cover everything in under 45 minutes. Add a "2 days" option to the days picker for plans that support it.
- [ ] New program "Dumbbells only" for 3 and 4 days a week, for home gyms or crowded gyms.
- [ ] Program links inside content: in the Start here cards and the Gym basics answers, link to the specific plan and tool that fits (for example the protein answer links to the calorie estimator).
- [ ] Pro principles deep dives: turn each of the six "Train like a pro" habits into a short expandable guide with practical steps for beginners.
- [ ] Workout log: let visitors record the weight and reps for each exercise in the program builder, saved on their device, and show what they lifted last time next to each exercise.
- [ ] Rest timer: a start button next to each exercise's rest time that counts down and gives a gentle beep or vibration when rest is over.
- [ ] Exercise how-to library: a short, plain-language form guide for every exercise used in the programs (setup, the movement, common mistakes), opened by clicking an exercise name.
- [ ] Body weight tracker: log a morning weight and show a 7-day average trend line, so the daily ups and downs matter less.
