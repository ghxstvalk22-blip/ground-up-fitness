# Roadmap

Add an idea anywhere under **Up next** and the daily update will build it, top item first.
Write it in plain words, like `- [ ] Add a page about stretching before workouts`.

## Up next

- [ ] Workout log: let visitors record the weight and reps for each exercise in the program builder, saved on their device, and show what they lifted last time next to each exercise.
- [ ] Rest timer: a start button next to each exercise's rest time that counts down and gives a gentle beep or vibration when rest is over.
- [ ] Exercise how-to library: a short, plain-language form guide for every exercise used in the programs (setup, the movement, common mistakes), opened by clicking an exercise name.
- [ ] Body weight tracker: log a morning weight and show a 7-day average trend line, so the daily ups and downs matter less.

## Ideas

- [ ] Warm-up section: a 5-minute general warm-up plus how to ramp up to working weights.
- [ ] Printable view of the current program (clean black-and-white layout for the gym).
- [ ] A home or dumbbell-only version of each program for people without a full gym.
- [ ] Protein food guide: common foods and roughly how much protein a typical serving has.
- [ ] "Your first day at the gym" checklist (what to bring, how to find equipment, what to do).
- [ ] Beginner glossary: sets, reps, RPE, progressive overload, deload, and so on.
- [ ] Export and import of saved data (workout log, weights) so people can move to a new phone.
